# Ая — живая помощница на рабочем столе

Аниме-персонаж поверх окон Windows: разговаривает голосом, слушает по клавише
или по имени «Ая, …», помнит, о чём вы говорили, включает музыку, ставит
напоминания и помогает с делами на компьютере — только с твоего разрешения.

## Установка

1. Открой [последний релиз](https://github.com/parh0m2007/Aya/releases/latest)
   и скачай **Aya_…_x64-setup.exe**.
2. Запусти его. Права администратора не нужны.
3. После установки откроется настройка — пара минут, по шагам.

### Если Windows предупреждает

Окно «Windows защитила ваш компьютер» — обычное предупреждение для программ
без платной подписи. Нажми **Подробнее**, потом **Выполнить в любом случае**.

### Где взять ключи

Мастер настройки подскажет сам, но вкратце:

- **Модель для ответов** (обязательно) — бесплатная облачная Ollama.
  Войди на [ollama.com](https://ollama.com/settings/keys) → **Add API Key** →
  скопируй ключ и вставь в мастер. Можно выбрать и свою модель: Ollama на
  компьютере или любой сервис, совместимый с OpenAI.
- **Живой голос** (по желанию) — облачный Fish, бесплатная модель.
  [fish.audio → API Keys](https://fish.audio/app/api-keys/) → создай ключ.
  Без ключа Ая говорит простым голосом.

Локальные голоса и ускорение распознавания на видеокарте NVIDIA можно
докачать по кнопке в мастере или в консоли.

## Как с ней говорить

- **Клавишей** — зажми Ctrl+Space в любом окне и говори. Работает, даже когда
  Ая свёрнута: она ответит голосом. Клавишу можно поменять: консоль → Голос → Клавиши.
- **По имени** — «Ая, напомни через час позвонить маме» (включается в мастере или в консоли).
- **Текстом** — двойной клик по Ае.
- Показать или спрятать Аю — Alt+Shift+A (тоже меняется в консоли).

Настройки, память, навыки, свои голоса и внешность — в консоли (трей → «Открыть консоль»).
Пройти первую настройку заново — консоль → Система.

## Где лежат данные

Всё твоё — в папке `%USERPROFILE%\.aya`: настройки, память и переписка
(`aya.db`), свои голоса и модели, докачанные наборы. Обновление и удаление
приложения эту папку не трогают.

## Для разработчиков

```
src/            окно и консоль (Vite + TypeScript + PIXI + Live2D)
src-tauri/      оболочка Tauri 2; ядро запускается вместе с приложением
core/           ядро на Python: FastAPI, SQLite, модели, голос, инструменты
scripts/        сборка Python для установщика, проверка перед публикацией
```

Запуск из исходников:

```powershell
uv venv core\.venv --python 3.11
uv pip install --python core\.venv\Scripts\python.exe -r core\requirements.txt
npm install
mkdir src-tauri\runtime\python, src-tauri\stage\core   # в установщик их кладёт scripts\build-runtime.ps1
npm run tauri dev
```

Тесты: `npx vitest run`, `core\.venv\Scripts\python -m pytest core\tests`,
`cargo test --manifest-path src-tauri\Cargo.toml`.

Релиз: тег `vX.Y.Z` → GitHub Actions собирает установщик и черновик релиза
(`.github/workflows/release.yml`). Перед публикацией —
`python scripts/check_public.py`.
