# Релиз Аи на GitHub: установщик для Windows и мастер первого запуска

Дата: 2026-10-28. Ветка разработки: `aya-redesign`.

## Зачем

Сейчас Аю может запустить только автор. Ядро работает из личного `core/.venv`
весом больше 5 ГБ, настройки лежат в его `~/.aya`, а ключи вписаны руками.
Цель — открытый релиз на GitHub. Человек без опыта скачивает установщик,
ставит его и за пару минут доходит до того, что Ая на столе здоровается голосом.

Главный критерий — **как можно меньше действий человека**:
- никаких терминалов, `pip`, ручного редактирования файлов;
- всё, что можно, заполнено по умолчанию;
- длинные загрузки идут в фоне, пока человек проходит следующие шаги;
- любой необязательный шаг можно пропустить.

## Цели

1. **Установщик.** `Aya-Setup.exe` для Windows 10/11 на странице GitHub Releases.
   Ставится без прав администратора и без отдельной установки Python.
2. **Мастер первого запуска.** После установки открывается он, а не Ая.
   Ая появляется на столе только после «Готово». Мастер можно пройти заново из консоли.
3. **Обновления в один клик.** Ая сама находит новую версию на GitHub и
   предлагает «Обновить».
4. **Сборка по тегу.** Тег `vX.Y.Z` запускает GitHub Actions, который собирает
   установщик и выкладывает релиз.
5. **Голосом из свёрнутого состояния.** Клавиша «говорить» работает, когда Ая
   свёрнута или спрятана в трей, и Ая отвечает голосом.
6. **Свои клавиши.** Можно переназначить клавишу «говорить» (сейчас Ctrl+Space)
   и «показать/скрыть Аю» (сейчас Alt+Shift+A).

## Не цели (в этом релизе)

- macOS. Он идёт следующим релизом: много кода ядра написано только под Windows.
- Платная подпись кода. SmartScreen покажет предупреждение, а на странице
  релиза будет инструкция, как его обойти.
- Telegram, Discord, музыка, MCP в мастере. Они остаются в консоли, а в
  конце мастера одна строка: «Ещё возможности — в консоли».
- Автоматическая установка Ollama. Локальную модель человек ставит сам, а Ая
  подхватывает список моделей.
- Облачное распознавание речи.

## Анти-цели (провал, даже если «работает»)

- Человек застрял в мастере: нет ключа, сбой загрузки, непонятная ошибка.
- Нужно открыть терминал или файл конфигурации.
- В открытом репозитории оказались ключи, токены или личные данные автора
  (переписка, имена, история чатов).
- Без интернета приложение не запускается или висит. Ответов без облачной
  модели не будет, но окно, консоль и мастер должны открываться.
- Обновление стирает настройки, ключи, свои голоса или скачанные модели.

## Решения (что выбрал автор)

### Платформа
Только Windows (10/11, x64). Mac — следующий релиз.

### Модель для ответов
- **По умолчанию:** облачная Ollama, `type: ollama`, `base_url: https://ollama.com`,
  модель `gemma4:31b-cloud`. Это рабочая конфигурация автора на сегодня.
  Человек вставляет только ключ.
- **Где взять ключ** — инструкция рядом с полем: войти на ollama.com →
  Settings → Keys → создать и скопировать. Плюс кнопка «Открыть страницу
  ключей», она ведёт на `https://ollama.com/settings/keys`.
- **Свой вариант** — ссылка «Другая модель» раскрывает поля:
  - тип: Ollama в облаке / Ollama на этом компьютере (`http://127.0.0.1:11434`) /
    сервис, совместимый с OpenAI;
  - адрес, ключ (не нужен для локальной Ollama), модель.
  Список моделей подтягивается сам у выбранного сервиса, выбирать из списка.
  Если список не пришёл, можно вписать название вручную.
- **Локальные модели** — это только модели для ответов через Ollama.

### Голос
- **По умолчанию:** облачный Fish, бесплатная модель `s2.1-pro-free`. Поле
  для ключа и инструкция, где его взять: fish.audio → API Keys.
- **Без ключа** (кнопка «Пропустить») Ая говорит бесплатным голосом Edge
  (`ru-RU-SvetlanaNeural`). Он уже работает в коде как запасной вариант.
- **Локальные голоса** (F5, VITS2, Qwen) — не входят в установщик. Мастер и
  консоль предлагают «Скачать локальные голоса (~N ГБ)» по желанию, загрузка
  идёт в фоне.

### Упаковка ядра — вариант A
- В установщик кладётся переносной Python (python-build-standalone) с уже
  установленными лёгкими пакетами. Ядро остаётся обычными `.py`.
- Тяжёлое ставится по кнопке встроенным `uv`:
  - ускорение распознавания на видеокарте NVIDIA (библиотеки CUDA);
  - локальные голоса (torch с CUDA, f5-tts, qwen-tts и веса).
- Отвергнуты:
  - PyInstaller: в замороженный exe нельзя доставить пакеты, антивирусы ругаются;
  - крошечный установщик с загрузкой Python при первом запуске: не работает
    без сети и даёт больше точек отказа.

### Репозиторий — чистый старт
- Репозиторий открытый.
- На GitHub уходит **новая история из одного коммита** с текущим кодом.
- Полная история остаётся у автора локально, в отдельной ветке, и не публикуется.
- Перед публикацией:
  - убрать из отслеживаемых файлов веса моделей
    `core/voice/f5_ru/ckpt/model_ru_v2_inference.safetensors` (1,3 ГБ) и
    `core/voice/dialogs_vits2/averaged_G_615000.pth` (505 МБ); они станут загрузкой;
  - проверить дерево на ключи, токены и личные данные.
- Вариант «переписать старую историю» отвергнут: высок риск пропустить секрет
  в одном из старых коммитов.

### Подпись
Без платного сертификата. На странице релиза и в README — картинка и шаги
«Подробнее → Выполнить в любом случае». Обновления подписываются ключом
Tauri updater. Ключ генерируется при сборке, автор кладёт его в секреты
репозитория (`TAURI_SIGNING_PRIVATE_KEY` и пароль).

### Клавиша «говорить» в свёрнутом состоянии
- **Сейчас:** запись по Ctrl+Space идёт, но если окно свёрнуто или в трее,
  распознанный текст выбрасывается (`src/main.ts`, `onRecStop`, ветка
  `else if (await isAyaHidden()) return;`).
- **Нужно:** Ая **остаётся скрытой** и отвечает **только голосом**.
  Окно не показывается. Ход сохраняется в историю как обычно.
- Поверх окон Ая уже держится (у окна `alwaysOnTop`), это не меняется.

### Свои клавиши
- **Где:** в консоли (раздел «Голос») и на шаге «Микрофон» мастера.
- **Поле «Клавиша, чтобы говорить»:** человек нажимает поле, потом сочетание
  или одну клавишу (F9, Ctrl+Shift+Space…), и оно сохраняется сразу.
- **Так же переназначается «Показать/скрыть Аю».** Сейчас это Alt+Shift+A,
  зашито в `src-tauri/src/lib.rs`.
- **Если сочетание занято** Windows или другой программой, это сразу видно
  в поле: «Это сочетание занято — выбери другое». Старая клавиша при этом
  продолжает работать.
- Значения хранятся в настройках ядра и переживают обновления.

## Мастер первого запуска (согласован с автором)

Окно мастера в стиле консоли. Слева шаги, справа содержимое, внизу
«Назад / Дальше». Каждое поле сразу заполнено разумным значением.

0. **Привет.** «Привет, я Ая. Настроим меня за пару минут», кнопка «Начать».
   Здесь же в фоне начинается загрузка Whisper small (~0,5 ГБ).
1. **Модель для ответов.**
   - Ключ ollama.com, инструкция и кнопка «Открыть страницу ключей».
   - Ключ проверяется сам сразу после вставки, без кнопки: зелёное
     «Ая на связи» или понятная ошибка («ключ не подошёл», «нет интернета»).
   - «Другая модель» — поля, описанные выше.
   - Шаг нельзя завершить без рабочей модели: без неё Ая немая. Ниже — ссылка
     «Пропустить пока», с предупреждением, что Ая не будет отвечать.
2. **Голос.**
   - Ключ Fish с инструкцией. После проверки звучит пробная фраза.
   - Выбор голоса из нескольких, у каждого кнопка «Послушать». Список — Fish-голоса
     из `FISH_VOICES` в `core/voice/tts.py`.
   - «Пропустить» — голос Edge.
   - Предложение «Скачать локальные голоса (~N ГБ)» с прогрессом в фоне.
3. **Микрофон.**
   - Выбор микрофона и индикатор уровня: «скажи что-нибудь».
   - Как звать Аю: клавишей (по умолчанию) или голосом «Ая, …».
   - Поле «Клавиша, чтобы говорить».
   - Состояние загрузки Whisper.
   - Если найдена видеокарта NVIDIA, предложение «Ускорить распознавание
     (~N ГБ)».
4. **Кто она.** Имя и внешность из нынешнего «Собери свою Аю»
   (`src/console/wizard.ts`), всё уже заполнено. Можно сразу нажать «Дальше».
5. **Готово.**
   - Галочка «Запускать вместе с Windows», включена по умолчанию.
   - Кнопка «Познакомиться»: мастер закрывается, Ая появляется и здоровается голосом.
   - Строка «Ещё возможности — в консоли».

Мастер помнит, где остановился. Если его закрыть посередине, при следующем
запуске он откроется на том же шаге.

## Что сейчас мешает и что придётся поменять (найдено в коде)

- `src-tauri/src/core_proc.rs` ищет ядро вверх от exe по `core/main.py` и
  запускает `core/.venv/Scripts/pythonw.exe`. Нужно уметь находить ядро и
  Python внутри установленного приложения (ресурсы Tauri).
- Ядро пишет и читает относительно папки проекта. Нужно перенести изменяемое
  в папку пользователя:
  - логи: `logs/`, `core_proc.rs` → `logs\core.out/err`;
  - `os.chdir` в `core/main.py`;
  - `Path("public") / "models"`.
- `core/requirements.txt` неполный: нет torch, faster-whisper, edge-tts,
  f5-tts, qwen-tts, numpy, soundfile, psutil, rapidocr и других. Нужно разделить
  на наборы:
  - базовый, входит в установщик;
  - ускорение на видеокарте;
  - локальные голоса.
  Версии закрепить.
- Голос по умолчанию — `tts_voice_id = "f3"`, это **локальный** голос F5.
  В релизе по умолчанию должен стоять Fish-голос, а без ключа — Edge.
- Локальные голоса читают веса из папок рядом с кодом (`_F5_DIR`, `_VITS_DIR`,
  `core/voice/qwen`). В релизе они качаются в папку пользователя, и код должен
  искать их там.
- В git отслеживаются два файла весов больше 100 МБ (см. выше).
- У репозитория нет удалённого адреса (`git remote` пуст).
- `localStorage` окна (запомненная модель аватара, позиция) переживает
  обновления, потому что папка данных WebView2 не меняется. Это нужно
  проверить, а не предполагать.

## Где что живёт после установки

- **Приложение:** папка установки, без прав администратора (установка «для
  текущего пользователя»). Её содержимое заменяется при обновлении.
- **Данные человека:** `~/.aya`. Сохраняются при обновлении и удалении
  приложения, если человек не попросил иначе. Это:
  - `config.json`, `aya.db`;
  - свои голоса, модели Live2D;
  - кэш TTS, логи;
  - докачанные пакеты и веса локальных голосов.

## Первый запуск и уже настроенные люди

- **Признак** — настройка ядра «мастер пройден».
- **Пока он не стоит,** главное окно Аи не показывается, открывается мастер.
- **Если в `~/.aya/config.json` уже есть рабочая модель для ответов** (это сам
  автор), мастер считается пройденным и не навязывается.

## Как понять, что готово

На чистой Windows (Windows Sandbox, она есть в Windows 10 Pro) человек:
1. скачивает установщик со страницы Releases;
2. проходит SmartScreen по инструкции;
3. ставит приложение без прав администратора;
4. проходит мастер, имея под рукой ключи ollama.com и fish.audio;
5. слышит, как Ая здоровается.

Плюс отдельно:
- Без ключа Fish всё то же самое, Ая говорит голосом Edge.
- Свёрнутая Ая отвечает голосом на клавишу.
- Своя клавиша работает после перезапуска.
- Обновление с версии N на N+1 через кнопку в приложении сохраняет
  настройки и ключи.
- В опубликованном репозитории нет секретов и файлов больше 100 МБ.

  - F5 `model_ru_v2_inference.safetensors` (1286 МБ) — `Misha24-10/F5-TTS_RUSSIAN`,
    скорее всего `F5TTS_v1_Base_v2/model_last_inference.safetensors`
    (размер совпадает, строитель сверяет по хешу). Лицензия **CC BY-NC 4.0**,
    только некоммерческое использование.

  Мы эти файлы не распространяем: человек сам качает их с Hugging Face по
  кнопке. Рядом с кнопкой ставим короткую пометку о лицензии.
- **Аватары в установщике** *(решение Claude)*: только Haru, она уже лежит в

  добавляет в консоли, как сейчас.
- **Установленная Ая и среда разработки** *(решение Claude)*: одновременно не
  работают, это нормально. Если ядро уже слушает порт 8330, установленное
  приложение использует его, как и сейчас. Общая папка `~/.aya` — это
  ожидаемо: у автора одни настройки.

## Оставлено строителю

- Точный способ встроить Python и пакеты в ресурсы Tauri и найти их из
  `core_proc.rs`.
- Куда `uv` ставит докачанные пакеты (отдельная папка в `~/.aya`, которую
  ядро добавляет в `sys.path`, или отдельное окружение) — главное, чтобы они
  переживали обновления.
- Откуда качать веса локальных голосов (страницы этих моделей на Hugging Face)
  и Whisper.
- Как устроить окно мастера: отдельное окно Tauri или раздел консоли.
- Набор и порядок проверок секретов перед публикацией.
- Конкретный текст инструкций и ошибок, по-русски и коротко.
