# Редизайн Аи — что изменилось и как проверить

Ветка `aya-redesign`. Точка отката — тег `pre-redesign` (это ваш код ровно таким, каким он был до начала работы, включая незакоммиченные правки).

## Коротко

| Что просили | Что сделано |
|---|---|
| Красивее и современнее | Консоль переделана по концепту `docs/design/aya-studio.html` («Aya Studio»): боковое меню, главная с аркой-превью, карточки, светлая/тёмная тема. Главное окно: стеклянная панель чата, пузырь реплик над головой, док с кнопками, меню по правому клику |
| Конструктор | Мастер «Собери свою Аю» из 5 шагов: имя и обращение → внешность (Live2D) → голос (с прослушиванием) → характер (роль, 5 черт, длина ответов, особенности) → модули. Из этого собирается системный промпт. 6 готовых образов, экспорт/импорт персоны в файл |
| Быстрее отвечать | Найдены и убраны 5 задержек, см. ниже. На вашей модели первый текст теперь через ~0.8–1.3 с, а раньше текст приходил только целиком в конце |
| Меньше ресурсов | Рендер стоит, когда окно спрятано; в простое 20 кадров/с вместо 30; один опрос ядра вместо четырёх; одно WebGL-превью в консоли |
| Удобнее | Enter/Shift+Enter, Esc, ↑ — прошлое сообщение; история при открытии чата; быстрые настройки прямо в окне; клики сквозь пустые места окна |
| Баги | 12 исправлено, список ниже |
| Взаимодействия с аватаром | Гладить (клик по голове или водить курсором над ней), тыкать (по телу), двойной клик — чат, правый клик — меню, Ctrl+колесо — размер, следит взглядом за курсором по всему экрану, губы двигаются по реальному звуку, мимика по настроению ответа, в простое оглядывается и дремлет |

## Почему было медленно

1. **Стриминг был ненастоящим.** `httpx.post()` дочитывает ответ модели целиком, и только потом отдаёт первый кусок. Теперь `client.stream()`.
2. **Однострочные ответы вообще не стримились.** Ядро ждало перевода строки, чтобы проверить, нет ли там JSON-действия. Короткий ответ без `\n` уходил одним куском в конце. Теперь обычный текст идёт с первого токена (`core/reply.py`, `StreamFilter`).
3. **Эмбеддинги долгой памяти считались до вызова модели**, синхронно и прямо в обработчике чата. Теперь в фоне.
4. **Первая фраза озвучивалась только после второй.** Теперь она уходит в TTS, как только набралось ~24 символа.
5. **Ядро замерзало целиком:** `import torch` в `/api/debug/metrics` (13 с), загрузка F5/VITS/Qwen и инструменты (поиск, скриншоты) выполнялись прямо в event loop. Всё это вынесено в потоки.

Плюс: общее keep-alive соединение к LLM (без нового TLS на каждое сообщение), в промпт идут только включённые инструменты (минус ~1000 токенов), индекс кэша озвучки по тексту (повторные фразы без загрузки модели), SQLite в режиме WAL.

## Исправленные баги

- Отладочная строка `pumpdbg` висела поверх аватара, каждый кусок речи слал лишний POST в `/api/_diag`
- Вкладка «Настройки» в окне Аи ничего не делала
- В `index.html` был лишний `</form>`, не было элемента для подсказки хоткея
- Без настроенной модели `/api/chat/stream` отвечал не NDJSON, и фронт писал «стрим оборвался»
- JSON-действие с текстом после него показывалось пользователю сырым (`json.loads` падал)
- Запасной голос edge-tts не работал никогда: `save()` асинхронный и вызывался без `await`
- Крестик консоли уничтожал окно, и «Открыть консоль» в трее переставала работать
- Звуки демо-моделей (японские фразы Haru) накладывались бы на голос Аи
- Любое нажатие на Аю сразу таскало окно: клик был невозможен
- Мимика не менялась от разговора: настроение только случайно дрейфовало
- Карточка Telegram опрашивала ядро каждые 5 с даже после ухода со страницы
- Каждое открытие вкладки «Персонаж» создавало новый WebGL-контекст (после нескольких переключений превью переставало рисоваться)

## Как запустить

Как обычно: `start-aya.cmd` (dev) или `start-aya-prod.cmd` (релиз уже пересобран). Старый релизный exe сохранён как `src-tauri/target/release/aya.pre-redesign.exe`.

При первом открытии консоли мастер предложит собрать Аю. Пока персона не собрана, Ая работает со старым характером по умолчанию.

## Чек-лист проверки

**Скорость**
- [ ] Короткий вопрос текстом: текст появляется по кусочкам, голос начинается до конца генерации
- [ ] Первый ответ голосом после запуска не «замораживает» окно

**Аватар**
- [ ] Клик по голове — смущается, румянец; клик по телу — вздрагивает
- [ ] Поводить курсором туда-сюда над головой — «гладишь»
- [ ] Двойной клик — открывается чат, ещё раз — закрывается
- [ ] Правый клик — меню (поговорить, погладить, тишина, размер, консоль, спрятать)
- [ ] Ctrl+колесо над Аей — размер, запоминается
- [ ] Перетаскивание окна за Аю работает, как раньше
- [ ] Клик по пустому месту рядом с Аей попадает в окно под ней (рабочий стол, браузер)
- [ ] Взгляд следит за курсором, даже когда он далеко от окна
- [ ] Губы двигаются в такт речи, а не равномерно
- [ ] Минут через 5 без мыши — сонная, через 10 — дремлет; шевельнуть мышью — просыпается

**Окно Аи**
- [ ] Ответы видны в пузыре над головой, когда чат закрыт
- [ ] В чате есть история, Enter отправляет, Shift+Enter переносит строку, Esc закрывает
- [ ] Кнопка ползунков в шапке открывает быстрые настройки, переключатели сохраняются

**Консоль и конструктор**
- [ ] Мастер: выбрать образ, имя, модель, послушать голос, подвигать черты, «Готово»
- [ ] После «Готово» имя меняется в окне Аи за ~5 с, смена модели перезагружает аватар
- [ ] Ая отвечает в выбранном характере
- [ ] «Персона» → экспорт и импорт файла
- [ ] Все старые настройки на месте: модели LLM, голоса, разрешения, MCP, Telegram, Discord, память, напоминания, журнал

## Облачный голос Fish — быстрее

Консоль → Голос → «Облачный голос Fish»: режим «Быстро» (low) / «Баланс» (balanced, по умолчанию) / «Качество» (normal), там же ключ.

| Замер (одна фраза) | Было | Стало |
|---|---|---|
| Синтез фразы до первого звука | 3,3 с (ждали весь mp3) | 0,6–0,8 с (звук потоком) |
| От Enter до первого звука в окне | ~4 с | ~2 с (из них ~1,2 с пишет модель) |

Как устроено: ядро берёт у Fish сырой PCM 24 кГц потоком и сразу передаёт окну, окно играет его кусками через WebAudio. Три фразы синтезируются одновременно. Одно соединение с Fish на всё время. Если Fish молчит 8 с или вернул ошибку — фраза звучит голосом edge-tts. После ошибки ключа или кредитов Fish пропускается 5 минут. Модель — бесплатная `s2.1-pro-free`.

WebSocket `/v1/tts/live` проверен и не встроен: первый звук 0,75–0,97 с против 0,52–0,76 с у HTTP, плюс ~1 с на подключение.

## Музыка (этап 1): YouTube и Яндекс Музыка

Говори «Ая, включи Кино — Группа крови», «пауза», «продолжи музыку», «следующий трек», «что играет?». Настройки: Консоль → Голос → «Музыка».

| | Как работает |
|---|---|
| YouTube | Ая ищет песню (yt-dlp, без ключа) и открывает её в браузере сразу с миксом — после песни идут похожие. Пауза и продолжение — мультимедийной клавишей. |
| Яндекс Музыка с токеном | Ая играет сама, в своём окне: полные треки (нужен Плюс), «Моя волна», «Мне нравится», после трека — похожие. Пауза, дальше, назад — всё работает. |
| Яндекс Музыка без токена | Ая находит трек и открывает его на music.yandex.ru, ▶ нажимаешь ты. |
| Пока Ая говорит или слушает | Музыка становится тише (или на паузе — как выберешь) и потом возвращается. |

Короткие однозначные команды («пауза», «следующий трек», «что играет», «продолжи музыку») ядро выполняет само, без первого запроса к модели. Так быстрее (~1 с), и модель не может «забыть» нажать. «Продолжи» и «дальше» без слова «музыка» остаются модели — это может быть «продолжи рассказ».

Найденные ограничения:
- **Яндекс Браузер не переключает трек клавишей «дальше»**: пауза работает, а следующий трек — нет. Ая это замечает и предлагает включить песню по названию. В Chrome и Edge «дальше» работает через плеер Windows.
- **Старое приложение Яндекс Музыки из Microsoft Store не работает** (пишет «Connection problems») и перехватывает ссылки music.yandex.ru. Поэтому сайт Ая открывает прямо в браузере. Вариант «Приложение» в консоли — для нового приложения с music.yandex.ru/download.
- Токен Яндекса: «Получить токен» в консоли → войти → скопировать значение после `access_token=` из адресной строки. Хранится только в `~/.aya`.

## Если что-то пойдёт не так

- **Окно Аи не ловит клики:** быстрые настройки (кнопка ползунков в чате) → выключить «Сквозь пустоту».
- **Ядро не стартует само:** смотрите `logs\core.err`; путь к проекту можно задать переменной `AYA_ROOT`. Старый способ (`start-aya-prod.cmd`) по-прежнему работает.
- **Прогулки или «Ая, …» мешают:** выключаются тем же переключателем в меню.
- **Отладка озвучки:** в DevTools окна Аи `localStorage.setItem("aya.debug","1")` включает прежний журнал `logs/tts-diag.log`.

## Откат

Вернуть проект в исходное состояние (код, ветку и незакоммиченные правки — ровно как было):

```powershell
git switch master
git restore --source=pre-redesign -- .
npm run build
```

Вернуть старый релизный exe:

```powershell
Copy-Item src-tauri\target\release\aya.pre-redesign.exe src-tauri\target\release\aya.exe -Force
```

Данные в `~/.aya` совместимы в обе стороны. Новые настройки (персона, модули, размер аватара) старая версия просто не читает.
